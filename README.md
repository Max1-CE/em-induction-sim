# Електромагнітна індукція: інтерактивний симулятор

Навчальний веб-застосунок з таких тем: закон Фарадея, правило Ленца, струми Фуко, двигуни постійного струму та асинхронні двигуни.
У кожній симуляції є анімація, слайдери, панель «що зараз відбувається», графіки в реальному часі, повна теорія з формулами
в **СГС (гаусова) і СІ** та блок «Перевір себе».

## Запуск

Потрібен Node.js 20+ (перевірено на 24 LTS).

```bash
cd em-induction-sim
npm install        # один раз
npm run dev        # дев-сервер → відкрити http://localhost:5173/
npm test           # юніт-тести фізичного ядра + smoke-тест інтерфейсу
npm run build      # продакшн-збірка в dist/ (відкривати через `npm run preview`)
```

> `index.html` не можна відкрити подвійним кліком: TypeScript треба зібрати. Використовуйте `npm run dev` або `npm run preview`.

## Розділи

| Вкладка | Симуляція | Модель |
|---|---|---|
| **1a** | Магніт крізь котушку, гальванометр | диполь; потік котушки аналітично; RL-коло з самоіндукцією; привід / вільний проліт / мишка |
| **1b** | Генератор (рамка в полі) | Φ = NBS cos φ, гальмівний момент 𝔪×B |
| **1c** | Провідник на рейках, перемикач «анти-Ленц» | ЕРС руху, сила Ампера; анти-Ленц порушує збереження енергії |
| **1d** | RL-коло з вимикачем | розв'язок через інтегрувальний множник τ(t) = e^{t/T}, порівняння з RK4 |
| **2a** | Магніт у мідній / алюмінієвій / … трубі vs пластикова | набір кілець; опційно — самоіндукція і взаємна індукція кілець; v_гр аналітично |
| **2b** | Маятник Вальтенгофена: суцільна пластина vs гребінка | функція струму ψ, рівняння Пуассона на сітці (метод спряжених градієнтів), карта \|j\| і лінії струму |
| **2c** | Електромагнітне гальмо (диск) | той самий розв'язувач ψ; M(ω) з максимумом (напівемпірично, див. нижче) |
| **2d** | Індукційний нагрів, шихтування, скін-ефект | формула тонкої пластини + точний розв'язок через ch((1+i)x/δ), перевірка теореми Пойнтінга |
| **3a** | Колекторний двигун / генератор | L İ/c² = U − IR − k_Φω/c, J ω̇ = k_Φ I/c − M; 1–3 котушки або ідеальний колектор |
| **3b** | Асинхронний двигун (трифазне обертове поле) | рамки клітки як RL-кола; M(s), формула Клосса |
| **3c** | Алюмінієва банка під обертовим магнітом | та сама модель, що й 3b |
| **4** | Довідник | одиниці СІ ↔ СГС, правила заміни у формулах, провідності, глосарій |

## Глобальні можливості

- **Перемикач СГС ↔ СІ** у шапці (за замовчуванням СГС). Фізика рахується лише в СГС, а перемикач змінює одиниці на слайдерах,
  осях графіків і в числових панелях. Він також міняє місцями формули в теорії: основною стає формула вибраної системи, друга показується дрібніше.
- **Правило Ленца на кожній анімації**: синій — зовнішнє поле, помаранчевий — поле індукованих струмів, бірюзовий — струм
  (яскравість ∝ |I|), червоний — сила / момент протидії. Кнопка «Силові лінії» показує або ховає лінії поля.
- **Керування**: пауза, крок кадру, швидкість ×0.1…×2, скидання.
- **3D-вид** (three.js, кнопка «🧊 3D») для генератора (1b), усіх симуляцій струмів Фуко (2a–2d) та двигунів (3a–3c).
  Сцену можна обертати мишею (ЛКМ), масштабувати колесом і зсувати ПКМ. Кнопка **«➚ Вектори»** показує об'ємні стрілки
  B, B інд, j / I, v, F, ω і M у тих самих кольорах, що й у 2D, а також легенду. Обидва вибори запам'ятовуються в localStorage.
  Модуль three.js завантажується ліниво, лише після першого вмикання 3D.
- **Енергетичний баланс** у кожній симуляції: графік E_мех, W_маг, Q, A_зовн і їхньої суми, а також відхилення суми у відсотках.
- Позначення: τ — інтегрувальний множник, **T = L/(c²R)** (СГС) / **T = L/R** (СІ) — стала часу.

## Що перевіряють тести (`npm test`, 42 тести)

- закон збереження енергії (< 1 % за 10 с) у 1a, 1b, 1c, 2a (з самоіндукцією і без), 2b (обидві пластини), 2c, 3a (двигун і генератор), 3b;
- теорема Пойнтінга в 2d (робота джерела = тепло + ΔW_маг);
- конвертація одиниць туди-назад дає тотожність, контрольні значення та узгодженість (U = IR, P = UI, Φ, L в обох системах);
- v_гр у 2a не залежить від початкової швидкості і збігається з аналітичною формулою;
  формула v_гр однакова в СГС і СІ;
- напрям індукованого струму в 1a відповідає правилу Ленца (sign ε = −sign dΦ/dt, сила проти швидкості);
  струми над і під магнітом у 2a протилежні;
- RL-коло: чисельний I(t) збігається з аналітичним розв'язком через τ(t) (похибка < 10⁻⁶);
- розв'язувач Пуассона перевірено на аналітичному розв'язку; гребінка гальмується слабше за суцільну пластину;
- 2d: межа тонкої пластини, правило n², δ однакова в обох системах; 3a: вихід на механічну характеристику;
  3b: чисельний момент збігається з M(s), максимум при s_k.

## Припущення та спрощення

- Квазістатика: струмом зміщення нехтуємо. Магнітна проникність провідників μ = 1.
- Магніт — точковий диполь (1a, 2a). Стінка труби тонка; кільця — нитки з опором 2πa/(σhw).
- 2a, самоіндукція: власна індуктивність кільця L = 4πa[ln(8a/g) − 2], взаємна — через еліптичні інтеграли на «згладженій»
  відстані √(d² + g²). Кільця далеко від магніту відкидаються (ковзне вікно ±6a), а їхню малу магнітну енергію зараховано в тепло.
  Цей режим рахується повільніше за реальний час.
- 2b, 2c: нехтуємо полем самих вихрових струмів (мале магнітне число Рейнольдса); поле полюса — квадрат з м'якими краями.
  У 2b гальмівний коефіцієнт K(θ) обчислено заздалегідь для 61 кута.
- 2c: спадання моменту при великих ω моделюється **напівемпірично**, M = −K₀ω/(1 + (ω/ω_c)²), ω_c = c²/(2πσ d r₀)
  (теорія рухомих зображень для тонкого листа). Мала-ω частина — точний розрахунок на сітці.
- 3b: рамки ротора незалежні (без взаємної індукції між ними і без реакції ротора на статор), поле статора задане.
- Якщо стала часу контуру T < 20 мкс, індуктивністю нехтуємо (I = ε/R), щоб явний RK4 не потребував мільйонів підкроків.
